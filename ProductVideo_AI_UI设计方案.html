05 / Guidelines

规范与交付说明

无障碍、响应式与开发交接的硬性要求，确保设计可被准确还原。

无障碍 · WCAG AA

  • 正文对比度 ≥ 4.5:1，大字 ≥ 3:1
  • 所有交互元素键盘可达，focus-visible 清晰
  • 状态用「颜色 + 文字 + 圆点」多重编码
  • 触控目标 ≥ 44px；不禁用缩放
  • 语义化标签与 aria 属性（如 tablist）

响应式 · Responsive

  • 移动 320–639 / 平板 640–1023 / 桌面 1024+
  • 卡片网格用 auto-fit + minmax 自适应
  • 窄屏隐藏侧栏，主导航改顶部
  • 创作页预览区在移动端折叠为可切换标签
  • 组件用容器查询按容器宽度调整

开发交接 · Handoff

  • 全部样式由 CSS 变量 token 驱动，暗色仅切语义层
  • 状态文案与后端状态机严格一一对应
  • 按钮/输入/徽章为复用组件，禁止各页重写
  • 字阶固定 rem，数据列用 tabular-nums 对齐
  • 动效用 ease-out 指数缓动，尊重减少动效偏好
