## 对话内容要点（后续开发依据）

- 产品：**ProductVideo AI** — 电商商品视频自动生成平台，首期垂直品类美妆护肤，风格「高级品牌感」，9:16 / 1080×1920 / 15~20s，30 天 MVP，目标副业 $500~2000/月。
- 商业分析：Remotion 是 source-available，Free（个人/3 人内组织）→ Automators $0.01/次渲染、最低 $100/月 → Creators $25/seat/月 → Enterprise $500/月起。
- 竞品三分类：代码驱动（Motion Canvas / Revideo / HyperFrames）、API 服务（Shotstack / Creatomate / Bannerbear / Plainly）、专业编辑（AE / Canva）。
- 技术架构（最终简化版）：模块化单体，Next.js + React + Tailwind/shadcn，Supabase PostgreSQL + Supabase Auth，Remotion + FFmpeg，Node.js Worker 用 PostgreSQL 表做队列（`FOR UPDATE SKIP LOCKED`），**文件存 VPS 本地磁盘**，Nginx + Ubuntu VPS（2vCPU/4GB 起）。
- 明确不用：Redis、BullMQ、S3/R2、AWS Lambda、K8s、微服务。
- 关键架构原则：**AI 只生成 JSON 参数，不生成 React 代码**；模板由开发者维护，Zod 校验参数。
- 数据表：users / products / video_templates / video_jobs / subscriptions / usage_records。
- 4 套模板：Product Launch(15s)、Product Highlight(20s)、Product Sale(15s)、Premium Showcase(20s)。
- 定价假设：Starter $19/30 条、Pro $49/100 条、Agency $99/250 条；新用户 3 条带水印免费额度。
